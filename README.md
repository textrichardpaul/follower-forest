# Follower Forest

Every follower gets a tree.

The web home of [@thefollowerforest](https://www.instagram.com/thefollowerforest): a single-file interactive forest world built with HTML, CSS, and JavaScript on canvas. Each follower of the account is planted as a named tree in a growing world of districts, houses, a kart circuit, a wheat field, a clubhouse, and the Founders' Golden Tree.

Live at [follower-forest.pages.dev](https://follower-forest.pages.dev).

## In the world

- Hundreds of individually placed, named trees, one per follower
- Districts with their own character, including Founders Street with resident houses
- Day and dusk lighting, find-your-tree search, tap a tree to see its resident card
- No build step and no dependencies: the whole world ships as one `index.html`

## About this repo

A public snapshot of the live build (November 8, 2026), shared as a record of the project. The forest keeps growing on the live site.
